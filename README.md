# Расчёт неопределённости методики

Одностраничное веб-приложение для лаборатории: ввод исходных данных, выбор типовых составляющих неопределённости, автоматический расчёт бюджета и оформление вывода в духе **ГОСТ 34100.3-2017** / ISO/IEC Guide 98-3:2008.

## Возможности

- Ввод реквизитов протокола и описания измеряемой величины
- Добавление составляющих неопределённости (тип A/B, распределения)
- Расчёт стандартной и расширенной неопределённости, коэффициентов чувствительности (где применимо)
- Формирование текстового протокола и печать
- Светлая и тёмная тема (кнопка в правом нижнем углу, выбор сохраняется в браузере)

## Требования

- **Только браузер** — можно открыть `index.html` или основной HTML с диска (`file://`), сервер не нужен.
- **Скрипты предпросмотра** — установите [Node.js LTS](https://nodejs.org/) (вместе с `npm`).

## Скрипты

Логика калькулятора по-прежнему внутри [`Расчет неопределенности.html`](./Расчет%20неопределенности.html) (встроенный JavaScript). В репозитории отдельно лежат **только сценарии запуска локального сервера** на порту **3000**:

| Как запустить | Описание |
|---------------|----------|
| `npm install` | Один раз: ставит зависимость `serve` в `node_modules/` |
| `npm start` | Старт сервера: каталог проекта → `http://localhost:3000` |
| `npm run preview` | То же, что `npm start` |
| [`scripts/serve.ps1`](./scripts/serve.ps1) | PowerShell: при отсутствии зависимостей выполнит `npm install`, затем `npm start` |
| [`scripts/serve.cmd`](./scripts/serve.cmd) | То же для cmd.exe (двойной щелчок или вызов из «Командной строки») |

После старта откройте в браузере `http://localhost:3000` — откроется `index.html` с переходом на основное приложение.

## Как открыть локально (без Node)

1. Клонируйте репозиторий или скачайте архив.
2. Откройте в браузере [`index.html`](./index.html) или сразу [`Расчет неопределенности.html`](./Расчет%20неопределенности.html).

Без сервера часть браузеров ограничивает возможности вроде `clipboard` — для полной проверки удобнее `npm start`.

## Первый коммит в Git

В каталоге проекта выполните:

```bash
git init
git add .
git commit -m "Initial commit: калькулятор неопределённости"
```

Привяжите удалённый репозиторий (`git remote add origin …`) и отправьте ветку (`git push -u origin main`).

## Публикация на GitHub Pages

Если нужен адрес вида `https://<user>.github.io/<repo>/`:

1. В настройках репозитория включите **Pages** с веткой `main` и папкой `/ (root)`.
2. Сайт откроется с корня (`index.html` уже перенаправляет на основной файл).

При желании можно переименовать основной HTML в латиницу (например `app.html`) и поправить ссылку в `index.html`.
